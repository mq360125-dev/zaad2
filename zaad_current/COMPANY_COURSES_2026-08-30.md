# ZAAD — Company Course Expansion — 2026-08-30

تمت إضافة محتوى شركات رسمي إلى قاعدة البيانات بدل تكرار الفرص.

## الشركات المضافة/الموسعة

- Salesforce Trailhead — Badges / Trails / Superbadges.
- HubSpot Academy — شهادات مجانية في التسويق والمبيعات وCRM والمحتوى.
- SAP Learning — Learning Journeys وRecords of Achievement؛ امتحانات SAP Certification منفصلة.
- Fortinet Training Institute — تدريب ذاتي مجاني ومسارات NSE؛ المختبرات والامتحانات قد تكون منفصلة.
- Red Hat Academy — دورات Linux/Ansible/OpenShift للطلاب عبر المؤسسات الأكاديمية المؤهلة.
- Adobe Experience League — تدريب رسمي في AEM وAnalytics وCommerce وFirefly؛ الامتحانات المهنية منفصلة.
- MongoDB University — مهارات مجانية وSkill Badges ومسارات Python/Node.js/GenAI؛ الشهادات المهنية لها شروط مختلفة.
- AWS Skill Builder — دورات رقمية مجانية، مع فصل واضح بين التدريب المجاني والشهادة المهنية.
- Google — موارد Google Cloud/AI/Data/Cybersecurity.
- Microsoft Learn — AI وPower BI وCopilot وApplied Skills ومسارات Azure.
- IBM SkillsBuild — AI وCybersecurity وData وCloud وAI Ethics مع Digital Credentials حسب النشاط.
- Cisco Networking Academy — Python والشبكات والأمن السيبراني.
- Meta Blueprint — موارد تعلم التسويق والإعلانات وAI؛ الشهادة المهنية منفصلة.
- NVIDIA Developer / DLI — دورات مختارة مجانية ذاتية التعلم.
- Oracle University — Foundations وOCI وJava وAI.
- GitHub Skills — تمارين عملية مجانية في GitHub Actions وCopilot وPages وغيرها.

## ملاحظة مهمة

المشروع لا يصف كل تدريب بأنه "شهادة معتمدة". يتم التفريق بين:
- شهادة/اعتماد رسمي من الشركة.
- Digital Badge / Skill Badge.
- Record of Achievement / Statement of Participation.
- إتمام دورة بدون شهادة مهنية.
- شهادة مهنية تتطلب امتحانًا مدفوعًا.

هذا التفريق مقصود لمنع عرض معلومات مضللة للطالب.
