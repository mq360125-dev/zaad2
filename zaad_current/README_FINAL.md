# ZAAD — زاد | النسخة النهائية

منصة خفيفة للطلاب لاكتشاف المنح والكورسات والتطوع والبرامج والمسابقات والتدريبات والمنصات التعليمية.

## التشغيل المحلي

```bash
pip install -r requirements.txt
python seed.py
python -m uvicorn main:app --reload
```

ثم افتح:

`http://127.0.0.1:8000`

## الاستضافة المجانية

استخدم أمر التشغيل:

```bash
uvicorn main:app --host 0.0.0.0 --port $PORT
```

إذا كانت المنصة تستخدم متغير `PORT` تلقائيًا فهذا الأمر مناسب لها.

## الواجهة

الصفحة الرئيسية تستخدم:

- بحث ذكي متعدد الكلمات.
- مرادفات للدول واللغات بالعربية والإنجليزية وبعض الأسماء المحلية.
- اقتراحات فورية أسفل مربع البحث.
- عمليات بحث سريعة.
- فلاتر متقدمة.
- صفحة تفاصيل كاملة عند الضغط على البطاقة.
- واجهة Responsive للموبايل والكمبيوتر.
- تحميل جميع صفحات API تدريجيًا بدل الاقتصار على أول 100 عنصر.
